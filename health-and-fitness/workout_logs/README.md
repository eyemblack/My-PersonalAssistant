# 🏃‍♂️ โฟลเดอร์สำหรับบันทึกประวัติการออกกำลังกาย (Workout Logs)

กรุณานำไฟล์ประวัติการออกกำลังกาย (เช่น `.tcx` หรือ `.gpx`) ที่คุณส่งออกมาจากนาฬิกาหรือแอปพลิเคชัน Zepp (Amazfit) มาวางไว้ในโฟลเดอร์นี้ได้เลยครับ

### 💡 วิธีใช้งาน:
1. นำไฟล์ที่ได้มาวางในโฟลเดอร์นี้ (คุณสามารถตั้งชื่อไฟล์เป็นวันที่ เช่น `2026-06-02_run.tcx` เพื่อให้อ่านง่าย หรือใช้ชื่อปกติที่เครื่องตั้งให้ก็ได้ครับ)
2. เมื่อโยนไฟล์เข้ามาแล้ว ให้พิมพ์บอกผมในแชทว่า **"โยนไฟล์ประวัติเข้าโฟลเดอร์แล้ว"**
3. ผมจะทำการอ่านไฟล์เหล่านั้นเพื่อวิเคราะห์ข้อมูลโซนชีพจร (Heart Rate), ความเร็ว (Pace), ระยะทาง และบันทึกผลพัฒนาการความฟิตของคุณลงในตารางสรุปผลย้อนหลังให้ครับ

---
*หมายเหตุ: โฟลเดอร์นี้รองรับทั้งไฟล์ `.tcx`, `.gpx`, `.csv` และไฟล์ข้อความสรุปครับ*
