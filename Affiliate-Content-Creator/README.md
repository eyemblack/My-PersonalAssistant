# 📱 Affiliate Content Creator Space

ยินดีต้อนรับสู่พื้นที่สำหรับวางแผนและสร้างสรรค์คอนเทนต์ Affiliate สำหรับแพลตฟอร์ม **TikTok, IG Reels, และ Lemon8**

---

## 📂 โครงสร้างโฟลเดอร์ (Folder Structure)

โฟลเดอร์นี้ถูกออกแบบมาเพื่อรองรับการทำเนื้อหา Affiliate อย่างเป็นระบบ:

*   **`planning/`**: สำหรับวางแผนกลยุทธ์ ตารางเวลาลงคอนเทนต์ และเป้าหมาย
    *   [`strategy.md`](file:///Users/opentechbox/Desktop/PA/Affiliate-Content-Creator/planning/strategy.md): แผนกลยุทธ์ กลุ่มเป้าหมาย และสไตล์ช่อง
    *   [`content_calendar.md`](file:///Users/opentechbox/Desktop/PA/Affiliate-Content-Creator/planning/content_calendar.md): ตารางเวลาการลงเนื้อหาและการติดตามผล
*   **`products/`**: สำหรับรวบรวมข้อมูลสินค้าที่ต้องการโปรโมท
    *   [`product_list.md`](file:///Users/opentechbox/Desktop/PA/Affiliate-Content-Creator/products/product_list.md): รายชื่อสินค้า, ลิงก์ Affiliate, ราคา, และจุดเด่น (Selling Points)
*   **`platforms/`**: แบ่งโฟลเดอร์ตามแต่ละแพลตฟอร์ม เพื่อความสะดวกในการสร้างคอนเทนต์เฉพาะตัว
    *   **`tiktok/`**:
        *   [`ideas.md`](file:///Users/opentechbox/Desktop/PA/Affiliate-Content-Creator/platforms/tiktok/ideas.md): ไอเดียทำคลิปและหัวข้อที่กำลังฮิต
        *   *โฟลเดอร์ย่อย `scripts/` (สำหรับเขียนสคริปต์วิดีโอ)*
    *   **`ig_reels/`**:
        *   [`ideas.md`](file:///Users/opentechbox/Desktop/PA/Affiliate-Content-Creator/platforms/ig_reels/ideas.md): ไอเดียทำ Reels และเสียงแผ่นเสียงฮิต
        *   *โฟลเดอร์ย่อย `scripts/` (สำหรับเขียนสคริปต์ Reels)*
    *   **`lemon8/`**:
        *   [`ideas.md`](file:///Users/opentechbox/Desktop/PA/Affiliate-Content-Creator/platforms/lemon8/ideas.md): ไอเดียและรูปแบบการเขียนโพสต์รูปภาพ/รีวิวแบบ Lemon8
        *   *โฟลเดอร์ย่อย `posts/` (สำหรับร่างแคปชั่นและเตรียมภาพประกอบ)*
*   **`assets/`**: สำหรับเก็บไฟล์รูปภาพ วิดีโอดิบ โลโก้ หรือเทมเพลตต่างๆ
