# 🎨 คลังเก็บภาพอ้างอิงดีไซน์ (Design References)

ใช้สำหรับวางภาพอ้างอิงต่างๆ (เช่น ภาพแคปเจอร์ปก Lemon8 ที่สวยงาม, Mood Board หรือพาเลตโทนสีที่ชอบ) เพื่อให้ AI สามารถนำไปวิเคราะห์และลอกเลียนแบบรูปแบบโครงสร้างการแต่งรูปภาพปกได้

---

## 📂 วิธีการใช้งาน
1. วางไฟล์ภาพอ้างอิงลงในโฟลเดอร์นี้ (เช่น `cover_ref_1.jpg`, `pastel_tone.png`)
2. เมื่อต้องการให้ AI เขียนงาน สามารถแนบรูปภาพเหล่านี้และแจ้งว่า *"ช่วยแต่งรูปในสไตล์เดียวกับไฟล์ [ชื่อไฟล์ภาพ ref]"* ได้ทันที
